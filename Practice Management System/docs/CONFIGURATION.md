Profession-specific terminology, fields, defaults, workflows, categories, and views may vary without changing the shared product direction.

No configuration mechanism is selected or implemented. Add only configuration supported by observed requirements from a completed vertical slice.

## Initial locale policy

The interface locale is Spanish for Paraguay (`es-PY`). Payment amounts are stored as unformatted whole numeric values and displayed as Paraguayan guaraní: currency code `PYG`, symbol `₲`, period thousands separator, and no decimal places (for example, `150000` → `₲ 150.000`).
