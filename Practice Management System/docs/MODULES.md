| Capability area | Current reality | Approved direction |
| --- | --- | --- |
| People | Client Directory and Client Detail | Broader relevant-contact Directory; model unresolved |
| Work | Client-owned Appointments and Sessions | Continue only through approved slices |

| Schedule | Client-scoped Agenda/Appointments | Richer calendar; Google Calendar is an integration candidate |
| Communication | Not implemented | Save → Send → Schedule → Automate; model unresolved |
| Capture | Quick Capture of ordinary Sessions and Payments | Cross-system interaction pattern |
| Memory | Client-scoped operational history | Easier retrieval; no global History object approved |
| Understanding | Client Total recibido and derived linked-session information | Analytics layer; KPIs unresolved |
| Follow-up | Not implemented | Approved capability direction; model unresolved |

This table is a capability map, not a backlog and not authorization to create new domain objects.
